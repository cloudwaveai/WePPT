# We-PPT：Office 操作与统一设计规则重构

依据：2026-11-05 用户会议反馈、《PPT空间层次拆解规则-v1》、pptreview素材筛选站。目标是减少完成工作的步骤，让普通用户无需编写设计提示词。

## 产品约定

- 三个主任务：从内容生成、打开已有PPT、统一改版。AI对话作为补充入口。
- 左侧页面列表承担加页、删除、复制和调整位置；新增默认紧接当前页。基础操作不调用模型。
- 配色和风格默认作用于当前整稿；仅当前页/仅后续新页为明确的次级选择。
- 粘贴、拖入、上传都是同一条参考图输入路径；1张即可开始，更多图片补充节奏依据。
- 长任务有真实阶段、完成页数、失败原因，可离开页面并在草稿中恢复；前端关闭不能丢任务。
- 改版与受众优化保留原稿；保留原始PPTX与图片。不因为导入器或模板限制丢页、丢图、漏内容。
- 按内容身份、数量、关系适配模板；内容多时调整构图，不能机械填槽或持续缩字。
- 不把“提示词已更新”“测试通过”写成审美已通过。上线前验证真实样稿、编辑、撤销与PPTX实物。

## 统一设计观

1. 先决定观众应理解什么，再组织证据和页面节奏。
2. 先构图，再空间关系，再材质与效果，最后检查可读性。
3. 参考图提供设计关系，不提供可搬用的事实、品牌、人像或口号。原生正文可编辑；复杂主视觉可作为独立图片层，不能把全文烘焙进整页图片。
4. 一套稿共享字体层级、色彩角色、留白与素材语言；页面之间通过主次、图文比例和密度变化形成节奏。不得用深色页配额、大色块配额替代设计判断。
5. 色彩按背景/正文/主色/辅助色分配角色；强调色用于重点。参考已有照片的色彩，避免每种颜色平均铺满。
6. 空间感可以来自遮挡、景深、转折或摄影自身光影。不能给每个框加阴影；不把浅色、透明和模糊混为一谈。
7. 图表用真实数据与正确关系。装饰不伪装成指标；待补充内容清楚标注。必要限制与事实不为简洁而删除。
8. 观察、估算与复刻建议分开。百分比坐标只作为参考分析；模型输出仍遵守实际场景schema和边界。
9. 参考素材里的英文眉题、重复页脚、平台按钮不自动继承。只保留用户材料与读者需要的信息。

## 实施顺序与验收

| 工作包 | 核心验收 | 状态 |
|---|---|---|
| 统一设计规则 | 策划/生成/单页适配/检查共享规则，取消冲突的装饰配额 | 已实现；3页真实样稿完成，审美待评审 |
| 直接编辑 | ＋在当前页后插入；删除可恢复；复制/移动；版本冲突保护 | 本地浏览器通过 |
| 参考图与整稿操作 | 粘贴1–3图；默认整稿配色/改版；高级参数折叠 | 配色与粘贴通过；真实解析成功；修复后单例改版 3/3 完成，稳定性和视觉仍待评审 |
| 已有文件 | PPTX打开到新项目，原文件保留，全部页面可追踪，不支持内容明确保留/报告 | 支持子集已验证；复杂对象整份拒绝 |
| 后台与草稿 | 任务不依赖浏览器打开，阶段进度与失败可见，原稿保留 | 持久化/重启/过期版本测试通过；原稿可见副本实际进度与失败；真实链路记录见报告 |
| 实物验证 | 本地Chrome交互、后端回归、前后截图与PPTX渲染 | 550 项 Python 全量通过；浏览器及实物已检查，失败证据与边界见报告 |

本轮先在本地完成可验证修改；部署需遵循既有备份和版本校验流程。素材站只读，不修改筛选结果。已有DEPLOYMENT.md的未提交修改保留。

## 当前可交付边界

新增页面不再依赖模型。改色与改版是不同操作：改色保持构图、确定性完成；改版按参考重新组织页面，在独立副本中执行。文档级操作现支持最近一次撤销；单页编辑沿用原有撤销/重做。尚未实现 Office 完整的多级文档历史。

打开已有 PPTX 当前支持 16:9 原生文字、简单形状及 PNG/JPEG 图片；表格、图表、SmartArt 等暂不支持的内容明确拒绝，不创建缺页副本。源文件和原始图片保持完整。受众/改版超过当前附件容量时直接报告，不压缩或删除图片继续执行。

独立证据：[重构验证记录](../../validation/office-rebuild-2026-11-05/README.md)。统一设计规则已经接入，但单套模型样稿不能证明各类内容的审美均已达标；未以几何评分替代人工看图。

改版新增原文保护：同一句状态文字在不同位置出现时不得去重。新副本冻结源页原文，在计划和页面保存前核对页数、页序和原文出现次数；检查不能代替对限定对象的人工看图。此前真实样稿漏掉一处“开发中”，已保留为失败证据，不能用于宣称改版验收完成。

最终改版复验：复用已解析参考档案，3/3 页在 323.56 秒完成，生成中无人工重试；原稿不变、原文次数保持。已渲染逐页查看，仍有空泛装饰和偏空布局，不以此单例宣称稳定 one-shot 或最终审美合格。见验证报告的最后一节。
