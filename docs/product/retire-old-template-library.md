# CD51 · 移除旧模板库

2026-11-05，用户明确要求原有七十多个模板全部删除。核对旧场景目录为75条；公开总目录还混有原稿参考、历史主题、开场模板与页面套件，共147条。

验收条件：
- 产品模板库只返回已确认的50套精选案例，旧75条及其他旧内置目录项不再出现；用户上传独立保留。
- 旧原稿图库入口转到精选案例；旧预览、选择、智能匹配、固定套系选择/应用接口返回410，防止旧链接重新应用。
- 新案例只作为设计参考，不伪装成可直接套用母版；预览打开8张代表图，真实正文仍由确认后的文案生成。
- AI新稿上下文不再提供旧模板推荐或候选，历史固定模板偏好不再自动绑定新稿。
- 已有稿件、图片、历史版本和已经保存的绑定任务保留，可正常读取/渲染；用户上传模板的查看和适配不受旧库停用影响。

实现边界：移除的是产品可选模板库及新生成路径。底层历史ID与渲染数据仅作为旧文档兼容保留，不进行用户项目数据库删除。不是仅隐藏按钮：服务端目录、推荐、应用入口同步停用。

本指令替代CD50中“新项目仍可明确选固定套系”的早先约定。当前唯一内置设计案例库为curated-designs.json的50条；历史固定套系的低层编译器仅用于已有文档兼容与回归验证，不再在产品中展示。

验收证据见`validation/retire-old-template-library/`。沿用PR #1交付，当前账号仍无上游写入权限；未合并或上线不得报告为线上已删除。
