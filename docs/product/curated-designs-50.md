# 精选50套案例接入

用户要求：把已经确认的50套加入WePPT。先讨论确认文案，再参考视觉语言，由AI随内容调整布局；不把50套伪装成50套可执行固定母版。

本轮单故事 CD50：
- 收录准确的50个来源、400张代表图、30套排版主库/20套视觉增强及各自短板；不改变筛选站状态。
- 设计栏可打开预览目录，搜索、筛选、展开和放大可用。
- 新建未绑定项目的模型上下文含50套简明目录；策略可保存有效的 `curatedReferenceId`，逐页生成继承该选择与适配规则。
- 未明确选择固定套系的新稿不再被默认固定套系接管；用户明确选定的套系、历史绑定页、用户配色和上传对标风格继续优先。
- 生成不能直接使用参考图作业务素材；不改变原文/原图/版本与同页约束。不存在的参考编号拒绝。
- 验证真实Studio任务上下文、策略往返、默认路由与固定套系回归；浏览器从设计栏进入预览。

## 结构与边界

`data/curated-designs.json`保存稳定的curated编号、原始库ID、来源、观察与建议。`curated_designs.py`向策划阶段提供简明目录，向逐页阶段提供整稿选定的案例；没有显式选择时提供最多3个候选。候选排序是简单词语匹配和角色偏好，不是视觉相似度模型。

在对话中可说“参考紫绿金属·品牌运动，根据我确认的文案调整排版”。模型把编号写入`strategy.curatedReferenceId`；原有content-led约定仍负责内容确认。本轮没有新增机械的确认按钮或把案例选择视作文案确认。

预览是采样图，不是原始PPT；图片与材质没有转换成可编辑原生元素。模型得到人工审阅的文字规则，不会自动把400张图发给视觉模型。未验证真实模型生成的审美效果；不能把接入或测试通过宣称为设计质量保证。

旧固定套系保持确定性编排。本地outline模式不会调用AI，不承诺实现材质风格。新稿自由排版走现有场景生成、校验与审查路径。

运行入口：设计 → 精选设计案例（`/curated-designs.html`）。源素材沿用来源标注；查看案例不授予第三方素材的再使用权。
