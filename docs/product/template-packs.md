# 内容与模板适配

> 2026-11-05 更新：四种空间方法已接入本地模板选择、内容适配与整稿改版。默认采用跨界错位；原三套历史模板仅为旧稿兼容保留。视觉方向仍待用户评审，工程测试不代表审美认可。测试网站已于2026-11-05更新为editor-69-spatial。

本轮把生成流程改成：输入大纲与正文 → AI 组织内容、选择同一套模板 → 按内容关系与容量选择变体 → 原生对象排版 → 浏览器测量 → 整稿检查。模板绑定页不再逐页调用模型重新画场景。

## 素材如何变成模板

素材数量与可执行模板数量分开记录。当前主入口有 4 个空间套系、36 个母版：字图穿插、跨界错位、透叠层面、同心浮雕。另保留 3 个历史套系、27 个母版，已有绑定与用户明确选择保持可解析；新项目不再默认展示历史套系。每个套系含封面、章节、尾页，以及分栏、宽行、流程、图文、层级和中心关系正文变体。

四个空间套系来自扩展素材参考册中已有看图分析的7页，来源、观察、必要关系与失效条件写入 `spatial-sources.json`。被账号选择不等于所有人认可。它们是对截图的可编辑解释，包含估算与派生版式，**不是原始 PPTX 的逐对象还原**。原图中的品牌、照片、文案和业务事实没有成为生成默认素材。

- `ppt_workbench/data/template-packs/spatial-sources.json`：四种空间方法的离线构建来源；`sources.json` 保留历史来源。
- `ppt_workbench/spatial_templates.py`：按真实内容与关系调整几何，源码指纹纳入模板版本，避免只冻结数据而漏掉编排器变化。
- `catalog.json`：可执行布局、字体、色彩角色、角色/关系/组数容量、观察与估算边界。
- `inventory.json`：区分参考素材与可执行套系；不把已有 44 个原页参考或服务器素材总量算作已编译母版。
- `scripts/build_template_packs.py`：不依赖网络或验证目录的离线构建器。

模板固定标题区、正文阅读区、颜色角色与分组规则。允许按真实内容组数重复模块、改变短文面板高度、把长分栏改成宽行、把原图完整放入图文区。不得自动删字、缩写、裁掉原图或擅自拆页。超出范围时报告容量冲突。

## AI 与规则各负责什么

AI 输出 `composition`、`template_id`，以及需要展示的本项目图片 ID `template_images`。一个内容组始终保留 heading、body、kicker、metric 的对应关系。中心关系图的第一组为中心，其余组为关联项；流程按组顺序连接；层级按组顺序排列。复杂拓扑与数据图表不属于这些基础变体的完整表达能力。

服务端固定一个套系，将模板选择写进逐页计划。模板内容哈希在创建整稿时冻结；生成途中母版变化会阻止继续。外部执行器不能提交另一套自由绘制的场景绕过模板绑定。页面仍由独立文字、形状、连线和原始图片组成，后续直接编辑保持可用。

模板内的初始排版先进行容量预检，再真实渲染并检查字体、图片载入和文字溢出。整稿模型审查只提问题，不以“骨架重复”为由自由重画母版。自动检查不能代替人的审美验收。

新建稿的默认路径使用套系。既有未绑定套系的任务继续原流程；用户明确选中的对标风格仍走其原路径。选择对标风格和选择模板套系会替换彼此的偏好，避免两套约束同时生效。

## 用户操作

设计 → 整套模板：同时看到封面、章节标题、正文三个预览。空项目选择一次，再输入大纲。已有页面点击“生成整套改版副本”，AI 在副本里重新组织原文的内容分组并匹配同套版式。

副本保留源稿、空间归属、重复的状态限定词、原始讲者备注和每页图片出现次数。原图字节不变。当前图文母版最多容纳每页 3 张图片；源稿超过此范围时拒绝创建缺图副本。源稿保留全部历史。选择模板不会只影响以后新增的页面。

## 尚未覆盖

当前是四种来源明确的空间方法，不是“任意复杂 PPTX 自动转为母版”的实现。更复杂的图表、自由拓扑、原生动画与全部材料库的转换，需要新增有来源的母版与相应验样。图片生成不是本路径的默认补洞方式；没有真实图片时使用文字版式。

本轮接入验证入口：`validation/spatial-integration-2026-11-05/index.html` 与 `README.md`；之前工程记录在 `validation/template-packs-2026-11-05/README.md`。运行结果、真实模型试稿与视觉验样分别记录，不把固定内容排版称为模型 one-shot。


空间方法不是完整素材复刻：字图穿插当前主要保留字体尺度与阅读轴，未完整自动形成后字/主体/前字三层遮挡；复杂摄影、玻璃/金属材质与任意拓扑仍需真实资产及相应布局。并列内容不因圆环母题被改成中心关系；只有明确 hub 才以第一组为中心。长文在同一套系内换宽行，排版预检使用最终净宽；侧标题不足时回到同套全宽标题。正文不低于24px，不截断或自动拆页。
