# PPT 空间层次拆解规则 v1

> 用途：分析参考模板、描述 PPT 设计要求、检查 AI 生成结果。
> 本版依据已讨论并认可的 9 张封面参考，整理可复用的分析与制作规则。

## 一、核心原则

**PPT 不能只安排元素的位置，还要设计元素之间的空间关系。**

需要同时考虑：

- **平面布局**：元素在哪里、多大、与谁对齐。
- **前后关系**：谁在前、谁在后、谁遮挡谁。
- **体积与材质**：元素如何通过厚度、光影、透明和纹理表现自身。

立体感不等于给所有元素加阴影。纯色图形可以通过遮挡和转折表达空间，照片也可能已经提供足够的光影。

**工作原则：先用布局组织信息，再用空间关系建立层次，最后用材质和光影强化表现。**

## 二、每个模板统一记录的 10 项内容

| 项目 | 需要记录的内容 |
| --- | --- |
| ① 位置坐标 | Logo、标题、信息、主视觉分别在哪里 |
| ② 尺寸比例 | 元素占画布多宽、多高，主次比例如何 |
| ③ 对齐与留白 | 共用哪条对齐线，元素之间保留多少距离 |
| ④ 前后层级 | 背景、中景、前景的排列顺序 |
| ⑤ 遮挡与穿插 | 谁遮挡谁，哪些元素跨越不同区域 |
| ⑥ 材质 | 纸张、玻璃、金属、纯色图形或摄影图像 |
| ⑦ 透明方式 | 整体透明、局部透明、透明渐变，以及透出什么 |
| ⑧ 光影 | 投影、内阴影、自身暗面、高光及光照方向 |
| ⑨ 边缘与厚度 | 描边、亮边、侧面、折面、边缘软硬 |
| ⑩ 裁切与出血 | 哪些元素超出画布，哪些被面板或形状裁切 |

### 坐标规范

统一使用百分比坐标：`[x, y, 宽, 高]`。

- 画布左上角为原点 `(0, 0)`，右下角为 `(100, 100)`。
- `x`、`宽`以画布宽度为基准；`y`、`高`以画布高度为基准。
- `x, y`表示元素外接框左上角的位置。
- 例如 `[6, 35, 46, 13]`：距左侧 6%、顶部 35%，占画布宽度 46%、高度 13%。

截图估算应注明测量的是可见边界，不应冒充原文件中的文本框或对象参数。对于出血元素，说明记录的是可见范围还是完整对象范围。

### 参数可信度

分析结果分开记录：

- **观察结果**：截图中可以直接看到的形态和关系。
- **估算结果**：根据截图估计的坐标、尺寸等。
- **复刻建议**：用于重现效果的实现方式和参数起点。

透明度、阴影模糊值等通常无法从截图唯一还原。浅色填充也可能看起来像半透明，不能仅凭颜色淡就断言使用了透明效果。

## 三、空间感的六种机制

| 机制 | 如何产生空间感 | 本次参考 |
| --- | --- | --- |
| 叠放遮挡 | 一个元素盖住另一个，建立前后顺序 | ① 复古窗口、② 白色面板 |
| 景深与虚实 | 远处淡、近处清晰，或使用照片自身景深 | ② 山景、③ 花瓶、④ 桌面 |
| 光影塑形 | 用亮部、暗部、投影表现形体与离底面的距离 | ⑤ 蓝色玻璃主体、⑦ 彩色折带 |
| 透明透叠 | 看见后方内容，并通过局部浓淡表现材质 | ⑤ 蓝色玻璃主体、⑦ 局部透色 |
| 厚度与转折 | 用侧面、折面、曲线变化表达立体结构 | ⑦ 彩色折带、⑧ 折叠色带、⑨ 扭带 |
| 跨界与出血 | 元素跨过面板边界或伸出画布，打破封闭分区 | ④ 照片条、⑥ 黄色横条、⑨ 扭带 |

**一页选定主要机制，再让其他效果辅助它，无需把六种全部堆上去。**

## 四、三个必须分清的概念

### 1. 投影、自身暗面要分开

投影落在其他表面上，表现物体与承接面的关系；自身暗面属于物体结构，表现厚度或转折。

例如，第 8 张的黑色折面不能简单替换成模糊阴影。复刻时，应先画对折面与接缝，再判断是否需要补充投影。

### 2. 透明、模糊、浅色要分开

- **透明**：决定能看见多少后方内容。
- **模糊**：决定细节是否清晰。
- **浅色**：只是颜色属性，不必然代表透明。

第 5 张的玻璃效果需要分别处理这些因素，不能只把一个蓝色图形调淡。

记录参数时明确区分透明度与不透明度：透明度 0% 表示完全不透明，透明度 100% 表示完全透明；不透明度的含义相反。

### 3. 图层顺序不等于完整的空间设计

仅仅把元素放在不同图层，还不足以产生可见层次。需要通过遮挡、错位、边缘、光影或透叠，让观众看出它们的关系。

例如，窗口遮挡照片、黄色横条伸出蓝色标题板、折带跨过文字区，都是可以直接感知的空间关系。

## 五、让 AI 制作时的描述顺序

1. **先定构图**：文字区、主视觉区、留白与对齐。
2. **再定空间**：谁在前后，在哪里发生遮挡或穿插。
3. **再定材质**：主视觉是纸、玻璃、金属，还是纯色图形。
4. **最后定效果**：透明方式、阴影、高光、边缘与厚度。
5. **检查可读性**：效果不能破坏标题、Logo 和关键信息的识别。

### 通用描述模板

> 画面采用【构图】，标题位于【坐标与尺寸】，Logo 位于【坐标与尺寸】。  
> 背景为【内容】，中景为【元素】，前景为【元素】。  
> 【元素 A】遮挡【元素 B】，在【位置】形成穿插。  
> 主视觉表现为【材质】，通过【侧面／高光／透明／投影】形成体积。  
> 【元素】跨越边界或伸出画布；文字区域保持清晰与足够留白。

### 示例：蓝色玻璃主体封面

不充分的描述：

> 左边放标题，右边放蓝色饼图，加一点阴影。

更完整的描述：

> 左侧约 45% 宽度放标题，右侧放分离的圆形主体。主体包含较实的蓝色扇形和半透明浅蓝外壳；外壳内有模糊蓝色层，边缘带细亮边，底部有柔和投影。背景圆形低对比、部分出血。文字保持清晰，不加立体效果。

该描述用于指导复刻，不代表对原模板内部图层结构的确认。

## 七、分析与验收标准

- [ ] **不编造参数**：观察结果、估算位置、复刻建议分别记录；无法确认的原始数值明确标注。
- [ ] **不默认加阴影**：先判断空间感来自哪里，再选择实现方式。
- [ ] **不混淆光影**：照片自带光影、物体暗面、页面投影分别处理。
- [ ] **前后关系可见**：观众能通过遮挡、错位、边缘或透叠读出层次。
- [ ] **效果协调**：光影、厚度与材质在同一物体或场景中保持合理关系。
- [ ] **主次明确**：主要空间机制清晰，辅助效果不过度争抢注意力。
- [ ] **阅读清晰**：装饰可以穿插，标题、Logo 和关键信息必须可辨认。
- [ ] **排除平台界面**：截图中的“编辑此页面”等平台按钮不作为模板设计元素。

## 八、原理参考

- [Google：Create shadows and clip views](https://developer.android.com/develop/ui/views/theming/shadows-clipping)——说明高度、遮挡与阴影之间的关系；可借鉴其空间表达思路，不把界面参数直接当作 PPT 标准。
- [Adobe：Transparency and blending modes](https://helpx.adobe.com/illustrator/using/transparency-blending-modes-alt.html)——区分对象不透明度、透明蒙版、混合模式及透明渐变。
