# 模板理解与内容适配

## 核心
模板是经过设计的视觉基础，不是限制文案的固定页数。使用实际参考图、案例分析及可编辑元素信息；区分稳定的风格特征、可替换内容、可伸缩区域和用户素材。按内容关系选择参考，保留识别性，而不是照抄参考文字或仅替换主色。没有看过的模板页面不得编造来源依据。

## 执行
- 新增页、AI插页、章节页、自动续页和局部重排都属于当前整稿，不能重新选择视觉风格。除用户明确换整套模板外，必须继承实际背景材质、字体家族、颜色角色、装饰语言和边距；允许根据内容设计不同布局。没有兼容布局或生成失败时保留同风格页面并标记待完成，不能静默使用通用模板。
- 每页明确参考来源、保留特征、为什么适合该页内容以及具体如何适配。封面参考不能自动证明正文设计适用；三项比较、五步流程、密集表格需要不同容量和阅读结构。
- 可复用的是字体比例、颜色角色、对齐轴、边距、图形外观、图像裁切及层叠关系。原有标题栏、阴影、透明度、摄影等精细设计能保留时不重画成普通矩形。
- 优先匹配合适容量的已有布局，再调整区域和组件数量。超容量时扩展结构、换兼容参考或按语义拆页；不得删减确认文案、随意缩小字号，或为了填满空间添加无关信息。
- 整稿可借鉴多个页面的表达方法，但受同一视觉方向控制，不能拼成不同风格。若内容必须超出参考构图，说明保留了哪些视觉特征，不假装是严格复刻。
- 用户 logo 和素材不随装饰替换丢失；品牌标识应使用用户素材，不沿用原模板公司的标识。调整区域时避开被保留对象，不能声称移动了接口无法修改的元素。
- 当前自由规划只支持已有渲染器提供的区域、照片及连线能力；不承诺原生图表、复杂蒙版或任意形状已实现。未分析的其余模板不宣称已经具备同等案例能力。共享来源及边界见 ../references/SOURCES.md。
