# 审美与设计方向

## 核心
视觉方向由受众、场景、内容密度和用户选定模板共同决定。先确定信息的主角、配角与阅读顺序，再安排颜色和装饰。统一整稿的字体层级、配色角色、图形语言、摄影及空间层次；视觉语言一致，正文按内容独立组织结构，不机械复用整页骨架；同类章节页允许统一版式，仍须可读且无缺字或遮挡。没有溢出只证明基础正确，不能证明好看。提出建议要指出具体区域和可执行变化，不用“更高级、更有设计感”代替判断。

## 执行
- 演讲页给主要结论更大面积与留白；阅读型培训页保留完整解释、条件和例外，依靠分组与标注提高可读性。留白应分隔信息和突出主角，不能留下大片无作用空地同时让正文挤成小块。
- 从所选模板找出可辨认的设计特征：标题与正文的比例、重心、边界留白、图片尺度及裁切、组件外形、黑白或彩色关系。保留这些特征，不能只取主色就声称沿用模板。既定字体缺失应说明替代，不默默改变视觉性格。
- 一个页面应有明确视觉焦点，主次由面积、字号、字重、对比和位置共同产生。正文段落优先便于阅读的对齐方式；连续间距使用一致尺度，相关信息靠近、无关信息分开。
- 图片服务内容或模板的叙事氛围，裁切保留主体和视线空间；避免无关装饰图、随意缩小照片以及到处等宽卡片。图表突出真正结论，流程保留方向与节点关系。
- 阴影、透明度和遮挡用来解释前后层次，光向与软硬一致。没有层叠目的就不加阴影；不得透过装饰降低正文对比。克制的平面风格也可成立，不强制每页图片、渐变或立体效果。
- 封面、章节、正文和结尾各承担不同节奏：重点页可更有表现力，正文以理解为先。变化应服务内容；只换颜色、挪动几个框、换卡片数量不算有效设计变化。
