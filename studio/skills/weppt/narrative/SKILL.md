# 文案与叙事

## 核心
先从对话确认用途、受众及希望受众理解或采取的行动；已有答案不再追问。区分演讲辅助与独立阅读：前者强调讲解节奏，后者需要自足的信息。每页围绕一个主要问题或观点组织，目录与小标题帮助定位。页数由内容关系和可读容量决定，不受参考模板页数限制。保留已确认的原文、事实、数字和素材；如需摘要、删减或改写，先遵守用户给定的修改权限。

## 执行
- 初次整理先形成“受众问题→主要结论→证据或步骤→下一步”的逻辑，培训可采用“情境→方法→示例→练习”，不要把所有用途强套同一种故事。
- 标题在内容允许时表达结论，目录、章节名仍可用简洁标签。不凭空补充数据、引用、成绩或时间。缺少事实时明确缺口，不以想象补齐。
- 识别比较、递进、因果、流程、并列和总分。内容分组依据意义，不能只按相同字数切段。长文拆页须保持条件与结论、步骤与解释相邻，延续标题说明各页不同重点。
- 避免连续“背景、现状、问题”空标签，也避免每页重复上一页。检查只读连续标题能否理解整稿主线；检查目录是否与实际章节相符。
- 用户只问建议时，给出具体页码、当前问题、建议结构和理由，不修改文案。用户确认建议后仅执行对应范围；保留原始细节，不能为了“大字少字”默认移入不可见备注。
- 当原文结构已清楚时直接保持，不为了表现聪明增加章节。密集培训稿可以有表格、完整规则和例外条件，不套英文每页50词之类硬限制。
