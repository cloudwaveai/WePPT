# 视觉审稿

## 核心
分别评价内容完整、设计表现和整稿一致性。真实图片、可编辑对象与检查结果共同作为依据；成功渲染不等于审美通过。没有看到的页面不作视觉保证，修改后的页面不能沿用旧图的通过结论。建议应定位具体页面、区域和可执行修正，不用泛泛的“优化排版”。

## 执行
- 新增/续页验收必须与同稿已完成页面并排核对实际背景材质、字体、配色、装饰语言、留白和层级。只有模板ID或主色相同不能通过风格验收；新增页明显变成另一套视觉风格属于需要修正的问题。局部修正仅限受影响页面，不覆盖已确认页面或手动编辑。
- 先查遗漏、错误数字、溢出、遮挡、不可读文字，再看主次、比例、留白、对齐、图文关系及模板识别性。文字虽然在画布内，但密得难读、标题太弱或图文尺度失衡，仍属于设计问题。
- 对照真实参考判断保留了什么：字体尺度、照片裁切、图形语言、色彩角色、阴影与透明层次。只有相似主色而丢掉其余特征，不能评价为模板还原良好。
- 整稿看连续缩略图，检查章节节奏、重复卡片和风格跳变。同类章节页允许统一版式，不因章节页主体构图相似要求重做；正文页保持一致视觉语言但按内容变化主体结构；指出重复页面及其应按内容调整的区域，要求可辨认的结构差异，不靠换色或改名通过检查。
- 一次建议聚焦最影响理解或审美的问题，指出位置、原因与操作，例如“第4页右侧正文过密，可扩大右区并减小装饰图”，而不是“第4页不好看”。不要为凑问题数量编造缺陷。
- 程序能测量的尺寸、溢出、对比等优先由本地检查完成；视觉判断再处理构图与风格。只修受影响页，修正轮数有上限，不把所有检查变成串行等待或无限循环。
- 审看与执行分开：用户只要求检查就不改稿；已允许自动修正时仍保护手动编辑。正文、素材或共享样式发生变化后，旧审看应标为失效。最终还要检查导出的 PPTX，浏览器中的正常显示不保证字体替换后的版面一致。
