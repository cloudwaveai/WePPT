# 单页设计

## 核心
每页先识别核心信息、内容关系、信息密度和可用素材，再选择表达结构。输出必须落在当前编辑器和接口支持的可编辑对象上；不能把整页图片当成设计结果。文案与数字完整，标题、正文、图片有清楚的阅读顺序，关键内容获得足够面积。

## 执行
- 比较页围绕共同维度对齐双方；流程页用有意义的连接与方向；总分页区分主结论和支持信息；数据页突出结论及其依据，不把不同关系都转成等宽卡片。
- 区域比例随文字长度与重要程度变化，但重要性不能仅由字数决定。可以不对称，也可以在真正并列时等宽。标题需要合理换行，不能孤立末尾一两个字；内容块留出足够内边距和行间距。
- 正文按内容独立设计，须有可辨认的结构差异；同类章节页允许统一版式；同类内容保持一致视觉语言，同时根据重点、密度和阅读顺序重新组织空间。禁止为了“每页不同”旋转文字、破坏对齐或制造错误流程；禁止用构图名称不同掩盖同一骨架。
- 精细处理文字、照片、边框与背景的层级。层叠不得遮挡正文或关键信息。照片裁切保留主体；连接线不穿过文字。间距要均衡，但不要机械均分所有空白。
- 设计前知道当前目标页与保留页；只返回要求修改的页。对用户手改对象、未选中对象和其他页面保持边界。单页请求不扩大为整稿重做。
- 用真实测量检查文字容量与边界，必要时修正容器和分组。审美解释应对应能看见的变化，例如“把关键结论放大、次要说明收进下方区域”，不能描述渲染器没有输出的质感、图表或3D物件。
