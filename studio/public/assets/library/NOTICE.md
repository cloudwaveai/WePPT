# Local SVG library

Generated with scripts/build-asset-library.mjs. No React is loaded by the application browser. Original MIT license texts are retained in licenses/. SVG artwork is normalized for local viewing; Coolshapes noise is disabled. Five upstream reference defects are corrected: literal shapeId in star8/star9, missing URL closing parentheses in wheel3/moon3, and a url()-wrapped clipPath id in flower4. Do not infer full native-export compatibility from catalog availability.

- Coolshapes 1.0.1: https://github.com/realvjy/coolshapes-react (MIT, 115 items)
- GeoPattern 1.2.3: https://github.com/btmills/geopattern (MIT, 64 items)
- Blobshape 1.0.0: https://github.com/lokesh-coder/blobshape (MIT, 36 items)
- Tabler Icons 3.50.0: https://github.com/tabler/tabler-icons (MIT, 6257 items)
