# 空间设计参考册

入口：[index.html](index.html)。可直接本地打开，不依赖外部脚本或字体。

## 这次增加了什么

从现有素材筛选记录展开到 46 套、368 页完整原图，包含封面、目录、章节、正文、结尾和结构页。亲自看图并记录 45 页的具体拆解：19 页封面、17 页正文、4 页章节、5 页结构图。其余页面明确标记「仅收录」，不声称全部审阅或认可。

每页拆解包含直接观察、必须保留的关系、适用内容、内容变化时的调整建议和失效条件。页面用途沿用来源标注，未通过标题自动推断；例如部分来源标题与图内文字不完全一致，不能把来源目录当内容真相。

13 个观察维度是可交叉标签：材质肌理、留白与重心、曲面与体积、字体尺度、拼贴与破边、摄影空间、跨界与出血、几何秩序、插画场景、光照与虚实、透叠与遮挡、图文穿插、层级与折面。它们不是 13 个成品模板，也不是互斥分类。

## 从扩大参考中得到的修正

| 观察 | 对产品的含义 | 可查看页面 |
| --- | --- | --- |
| 材质的作用来自细节、光照和尺度，无法只用颜色代替 | 参考需保留视觉资产依赖，不能一律压平成矩形 | R01-01、R31-01、R37-01 |
| 空间感可以由纯平面遮挡建立，不必每页三维化 | 图文穿插、错位、跨边界也是独立方法 | R44-01、R20-04、R11-04 |
| 正文能保留套系身份，同时降低强视觉的面积 | 记录封面到章节到正文的变化方法，不冻结同一套坐标 | R01-01/03/04、R04-01/03/04、R31-01/03/04 |
| 同一配色下，正文可能仍然机械 | 不能凭封面接受整套；正文独立评审 | R14-04、R19-04、R38-04 |
| 折面、顶面、侧面建立结构；阴影不能替代它们 | 图形需携带面之间的关系与真实拓扑 | R42-02、R42-04 |
| 图形也会暗示数据或顺序 | 检索需先核对内容关系，不能给并列概念强加层级或走势 | R31-04、R42-01/03/05 |

## 尚缺什么

- 本轮来自既有筛选快照，主要为 Canva 模板截图，不代表全部 645 条材料的覆盖，也不是跨来源审美共识。
- 截图能支持可见关系分析，不能提供精确原生图层、字体许可、透明度或材质参数。将复杂素材用于生成前，仍需确认对应原始素材与使用条件。
- 已覆盖的照片/材质类较多；严肃数据图、复杂系统图、真实业务实屏与高密度报告页仍需结合已有原生 PPT 模板库补充。
- 尚未完成「同内容、多种设计」和「同设计、不同内容」适配样张。本册未接入生成链路，旧套系的 rework 状态保持不变。

## 文件与验证

- `catalog.json`：全部原图清单、来源链接、来源角色、字节数、SHA-256；不含账号身份。
- `analysis.json`：45 页结构化拆解，是参考册的分析数据源。
- `write_analysis.py`、`build_atlas.py`：分析记录与网页生成来源。
- `assets/`：368 个服务器原始文件，未改编码、未缩像素。显示时保持比例，可打开完整原图。
- `download-verification.json`：全部文件与服务器 SHA-256 一致。首次 tar 最后一页不完整，已保留说明；逐项核验后单独补取该页，没有覆盖原文件。
- `check_atlas.cjs`、`browser-check.json`：实际用本机 Chrome 打开，核对全部原图载入、筛选、搜索、同套切页、两图对照、窄屏布局与打印样式。浏览器连接宿主不可用后使用本机独立 Chrome 验证，没有操作用户登录会话。
- `atlas-desktop.png`、`atlas-detail.png`、`atlas-comparison.png`、`atlas-mobile.png`：页面实际截图。已亲自查看，非生成 PPT 的前后对比图。

没有修改应用运行逻辑，没有发布，没有调用模型生成或删除用户素材。交互检查仅证明本册可用，不代表美感或内容适配验收。
