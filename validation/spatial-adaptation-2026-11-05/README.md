# 空间设计关系适配验样

2026-11-05。入口：[index.html](index.html)。本轮完成的是人工编排的关系适配样张，不是自动生成产品的最终验收。

## 这轮验证什么

以同一份We-PPT需求文本制作四种空间方案，每种4页：封面、章节、简正文、密正文，共16页。另将完全相同的文字与封面原始实屏输入被否定的 `forest-editorial-v1`，生成4页旧路径对照。用户可以看参考与适配、同内容两种设计、旧模板与新样张。

正文表达用户提出的产品目标，不把目标写成已上线能力。内容源维护于 `content.json`，原始图来源见 `asset-provenance.json`。

| 方法 | 原页依据 | 本次迁移的关系 | 未迁移或仍有不足 |
| --- | --- | --- | --- |
| 字图穿插 | R44-01 | 后方巨字与前景主体形成遮挡，密页用大标题保持重量、正文沿一条阅读轴展开 | 实屏替换了人物照片；原图的完整“后字—照片—前字”三层没有全部还原，不能称忠实复刻 |
| 跨界错位 | S201-01、S201-04、R20-04 | 主体跨过深浅背景边界，露出的错位底板建立前后，正文以共轴与错位阅读带延续 | 没有摄影资产本身的纵深与材质；密页仍有较强规则性，需要继续比较内容变化后的灵活度 |
| 透叠层面 | R42-05 | 后层在透明板下可见，实色文字与透明装饰分开；密页将透叠集中到阅读面边缘 | 迁移透明层面的关系；没有原锥形外壳与内部四层结构，不声称玻璃材质或精确透明度复现 |
| 同心浮雕 | S350-01、S627-01 | 共心层面靠统一边缘明暗分离，正文缩小圆形，为文字让位；四组条件有共同对象 | 独立椭圆和统一轻影的可编辑近似，未复刻复杂材质；圆形不表示任何数值比例 |

这些参考未获用户审美认可；样张也不自评accepted。页面角色不是模板设计能力的完整范围，四种方法也不是素材库的全部设计词汇。

## 内容与实物检查

- 全部样张用产品现有 `validate_scene`、`render_html` 和 `export_pptx` 路径生成。没有改应用运行逻辑、没有连接自动选版、没有发布。
- PPTX每页保留独立原生文字和形状。XML逐对象读回核对原文；封面中的本地开发版完整实屏以原始PNG字节嵌入，未压缩、裁像素或转编码。
- Chrome检查20页预览的字体、图片载入和文字溢出；整页原图、同内容切换和窄屏交互另检。逐页机械检查不能代替空间关系或审美判断。
- LibreOffice实际渲染为PDF与PNG；PDF按原生内容流读回全文。已查看导出页和浏览器页。PowerPoint桌面版未测试。
- 密正文的四组身份、顺序和限定条件原样保留。样张中的封面实屏是2026-11-05本地演示项目，不是线上功能验收证明。

最终证据：`metrics.json`、`office-render-check.json`、`office-render-check-*.json`、`browser-check.json`。每套目录包含可编辑 `sample.pptx`、浏览器 `pages/*.html` 与 `pages/*.png`、真实导出 `pptx-rendered/sample.pdf` 和 `page-*.png`。图片按原始字节另归档，见 `image-archive-manifest.json`。

## 看图后做过的修正与保留问题

首次浏览器测量发现四个封面主标题的字体实际高度超过框高，已扩大文本框。看图又发现字图与同心两种密正文仍接近通用两栏，已在保留原文的前提下改变构图；修改前整套原文件保留在 `iterations/first-reviewed/`。

首次PDF文本检查使用布局模式，双栏行被交错抽取，导致长段连续匹配失败。改为读取PDF内容流，继续逐段核对全文，未删掉文本校验。首次网页检查发现说明链接指向尚未创建的README，补齐后复验。

目前的主要缺口是素材依赖：摄影透视、真实材质、破边拼贴与复杂折面还不能靠现有矩形、椭圆和文字自动获得。后续应按原始设计资产补齐，并用真实内容独立验样，不能换颜色后就宣称全部空间方法已实现。

## 可复现入口

- `build_samples.py`：四种独立关系构图；正文只有一个来源。
- `build_baseline.py`：相同文字、相同原始截图的旧路径对照。
- `build_viewer.py`：参考与适配的交互入口。
- `render_browser.cjs`：实际Chrome渲染和文字溢出检查。
- `render_exports.py`：LibreOffice实物渲染与全文读回。
- `check_viewer.cjs`：参考图、16页切换、旧路径对照、方法比较、窄屏和打印检查。

重新生成前保留已有产物；图片不可覆盖归档原件。HTML引用上一级原图参考，移动时须保留相对目录关系。没有调用模型或付费生成服务。
