# 编辑器与 AI 快捷推荐验证 · 2026-10-29

> 这是发布前的本地验证记录。后续已部署公网并验证真实模型，最新结果见 [公网发布验证](public-2026-10-29.md)。

本轮基于已有工作区继续修改，保留原有未提交变更。没有提交 Git、部署远端或更改真实业务项目。浏览器使用独立的本地演示项目。

## 已实现

- 顶部功能区、左侧缩略图、中央画布、可收起的右侧 AI 助手；手机端保留页面切换。
- 文字、字体、字号、颜色、加粗、斜体、段落对齐；画布双击编辑、拖动移动、四角调整显示尺寸、方向键微调、缩放视图。
- 当前页直接编辑和已应用建议的多步撤销、重做；历史保存在 SQLite，重启可恢复。其他入口更新本页时重新开始直接编辑历史，避免用旧历史覆盖新内容。
- AI 推荐接入现有 Codex / Claude Code 执行器，限定局部 scene_patch。生成仅保存建议，前后预览和文字差异可检查；用户应用后才更新当前页。对象范围、项目隔离、版本冲突和重复应用均由服务端检查。
- 排版与层级推荐禁止改写原文或缩小字号；图片来源不可由快捷建议替换。图片文件未压缩、未转换，调整仅作用于显示几何。
- 旧项目通过已保存 Scene 获得当前编辑交互，不重写已有登记产物。

## 当前边界

- 仍为单对象编辑，未实现多选、组合、旋转、完整剪贴板或 PowerPoint 全部能力。
- 撤销/重做针对当前页的直接编辑与已应用建议，不跨页撤销所有聊天和模板操作。
- 本轮验证 PPTX 包结构与原生对象内容，未在 Microsoft PowerPoint 中验证字体与最终排版。
- 素材联网检索、Logo 独立入口、受众复用和个性化推荐仍属于后续批次。

## 可复现命令

```sh
PYTHONPATH=tests .venv/bin/python -m unittest tests.test_editor tests.test_studio tests.test_rendering tests.test_http tests.test_scene_operations -q
node --check ppt_workbench/web/app.js
node tests/ui_logic.mjs
git diff --check
```

浏览器验收脚本 `tests/editor_browser.cjs` 必须使用独立演示项目，它会实际修改演示页。通过 `PPT_STUDIO_TEST_URL` 提供当前本地启动链接，通过 `PPT_PLAYWRIGHT_MODULE` 指定已安装的 Playwright 模块，不把访问 token 写入源码。
