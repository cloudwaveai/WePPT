# 内容容量与断行改进（2026-10-31）

目标：在生成前让文案与构图一起规划；在实际渲染后提供断行证据，减少等宽窄栏、末行孤字和模型自加的重复文案。保留用户原文、事实和同页要求，不自动删减已保存内容。

## 改动

- 为策划复核和逐页生成提供每组字符数，以及26px正文在等宽栏中的行数估计；仅供比较构图，不是固定模板、字体规范或真实字体测量。
- 模型草稿复核区分标题、组标题和正文作用；要求正文提供新的机制、例子或边界，避免重复标题与口号式收尾。
- 浏览器等待字体后，用DOM Range读取文字实际行数、末行及字号。三行以上且末行只有1–2字符时标为候选；主动换行短段不误判。候选只提供证据，仍由模型结合画面判断。
- 单页／整稿检查收到实际断行证据；优先加宽正文、重新分配区域或改变路径，不用持续缩字维持槽位。调用上限、原文保护、版本保护保持。
