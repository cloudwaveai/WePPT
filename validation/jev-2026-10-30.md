# Command Code / Jev 智能选版（2026-10-30）

## 实现

- 使用用户最后提供的新密钥，服务器独立文件 `/opt/weppt/config/commandcode.env`，权限 0600；不写入源码、镜像或前端。原 Codex 凭据和模型配置保持。
- 固定官方 HTTPS 端点，模型 `typesafe/jev-1.14.0`。禁止跟随重定向，显式标识 `WePPT/1.0`；默认 Python 客户端被供应商返回 403/1010，使用应用标识后真实调用 200。
- 页面样式增加“智能选版”。GET 列表/规则推荐不调用模型；仅点击按钮的 POST 发起决策。
- 根据当前已编辑文字、页面角色与图片数量筛出最多 12 个不同底层版式。仅向模型发送当前页文字、图片数量与候选说明；不发送图片文件、密钥以外的账户资料或整个项目。
- 返回候选 ID 和概率用于排序，最多展示 6 项；有效性与概率分布校验，不允许新造模板 ID。低置信度、超时、响应无效、繁忙或未配置时保留规则匹配。此匹配是建议，不保证视觉质量或模板容量一定满足全部内容。
- 10 分钟内相同内容复用结果，失败缓存 30 秒；全服务最多一个进行中的决策请求，外部请求最小间隔 2 秒。没有自动重试或轮询模型。
- 决策不修改页面。请求前后校验页面版本，前端忽略切页后的旧响应；应用模板仍走原有预览和撤销流程。
