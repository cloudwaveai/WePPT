# 项目字段

空白 `brief.json` 有意不替用户填立场。可先创建空项目，通过 next_action 逐项补充。

| 字段 | 含义 / 可选值 |
| --- | --- |
| title | 项目标题 |
| purpose | proposal 方案、report 汇报、pitch 推介、teaching 讲解、other 其他 |
| purposeOther | 其他用途的具体说明 |
| audience | 听众身份、已有认知 |
| outcome | 希望促成的理解、决定或行动 |
| delivery | live 现场讲述、read 独立阅读、both 两者 |
| duration | 时长或篇幅限制，以文本记录 |
| logoPolicy | undecided / none / company / joint |
| logoReference | 项目目录内的准确 Logo 文件相对路径 |
| brandReference | 已有品牌/设计参考说明或文件引用 |
| dataPolicy | undecided / user / research / mixed / none |
| scopeNote | 必须讲、不能讲、对外披露边界与范围 |

数据策略只说明由谁提供资料，不表示资料已经真实、完整或通过核验。
