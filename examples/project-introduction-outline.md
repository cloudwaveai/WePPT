## 对比｜从反复解释到集中反馈
结论：把整套任务保留下来，减少重复说明
反复解释

集中反馈

一次指出多页问题，系统分别执行并汇总结果。

## 流程｜三轮交互怎样安排
结论：后台可以反复制作，用户集中表达意见
提供思想与材料，查看完整初稿。
集中补充和反馈，查看整套修订结果。
检查并确认整稿，导出可编辑文件。

## 对比｜两种对话入口
结论：网页与 Coding Agent 使用同一份项目状态
网页对话
边说边看实际页面。
选中对象提出修改，集中确认整稿。

Coding Agent 对话
Claude Code 或 Codex 通过 CLI、MCP 操作。
先读取任务和版本，再按页提交修改。

## 章节｜第二章：把修改做准确
结论：准确执行反馈，再检查当前页面
用户的一次反馈可以涉及多页。
系统内部仍逐页处理，避免误改其它页面。

## 并列｜检查、记录与交付
结论：每一步都对应实际页面与版本
检查：识别文字溢出、重叠和对比度问题，区分估算与浏览器测量。
记录：保留输入轮次、逐页改动、失败任务与当时版本。
交付：整稿确认后检查交付条件，提供 HTML 与可编辑 PPTX。
